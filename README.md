# ⚽ FIFA World Cup Player Analytics & Performance Dashboard

A professional, interactive web application built with **Streamlit** and **Python** to explore, visualize, and compare authentic FIFA World Cup player and team statistics sourced from FBref.

---

## 🚀 Key Features

- **📊 Player Statistics & Dashboard:** Explore comprehensive tournament data, filter by national teams, and analyze top goal scorers and assist providers with dynamic Plotly charts and team goal share distributions.
- **⚔️ Team Comparison:** Compare multiple national squads side-by-side using aggregate metrics and detailed player rosters.
- **👥 Player Head-to-Head:** Direct comparison tool between any two players featuring dynamic avatars, direct metrics, and comparative bar charts.
- **🏳️ National Flag Integration:** Automatic emoji flag mapping for all participating countries to enhance the UI.

---

## 🛠️ Tech Stack

- **Python** (Core Logic & Data Processing)
- **Streamlit** (Interactive Web UI Framework)
- **Pandas** (Data Manipulation & Cleaning)
- **Plotly** (Interactive Data Visualizations)
